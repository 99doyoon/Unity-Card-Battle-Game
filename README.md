# Unity Card Game Project

## 프로젝트 소개

Unity를 사용해서 간단한 카드 기반 턴제 게임을 만들어보는 프로젝트입니다.
게임의 기본 구조와 흐름을 직접 구현해보면서, 전체적인 동작 방식을 이해하는 것을 목표로 진행했습니다.

---

## 개발 목적

* Unity UI 시스템(Canvas, Panel 등) 이해
* 카드 드래그 앤 드롭 구현
* 턴 기반 게임 로직 구성
* 게임 흐름 관리 (시작 / 진행 / 종료)

---

## 구현한 기능

### 1. 카드 드래그 시스템

카드를 마우스로 선택해서 원하는 위치로 이동할 수 있도록 구현했습니다.
드래그 중 UI가 자연스럽게 따라오도록 처리했고, 특정 영역 밖으로 이동하면 카드가 사라지거나 무효 처리되도록 했습니다.

---

### 2. 턴 관리 시스템 (TurnManager)

플레이어 턴과 적 턴이 번갈아가며 진행되도록 구성했습니다.
턴이 변경될 때마다 상태를 갱신하고, 카드 사용 가능 여부를 제어하도록 했습니다.

---

### 3. 카드 덱 / 디스카드 시스템

* 카드 사용 시 Discard 더미로 이동
* 덱이 비었을 경우 Discard를 다시 섞어서 재사용

기본적인 카드 게임의 흐름을 구현했습니다.

---

### 4. 게임 상태 UI

* Game Over 화면
* Victory 화면

게임 종료 시 상황에 맞는 UI가 표시되도록 처리했습니다.

---

## 진행하면서 배운 점

처음에는 단순히 기능만 구현하려고 했지만, 실제로는 객체 간의 흐름을 이해하는 것이 더 중요하다는 것을 느꼈습니다.
특히 카드, 턴, UI가 서로 어떻게 연결되는지 고민하면서 구조를 잡는 경험을 할 수 있었습니다.

또한 Unity에서 UI 이벤트 처리와 게임 로직을 분리하는 것이 중요하다는 것도 알게 되었습니다.
